# DSO Service 7 — Πλάνο Παράδοσης (αναθεωρημένο)

Βάση: D2.2 §2.6.7 και η αναφορά `SUMMARY.md`.

---

## 1. Τι παραδίδουμε

Ένα service **επικύρωσης τοπολογίας** για δίκτυα ΧΤ, σε δύο λειτουργίες:

| Λειτουργία | Είσοδος | Έξοδος | Ακρίβεια |
|---|---|---|---|
| **Διόρθωση** | τεκμηρίωση + φυσικά υπαρκτές συνδέσεις + μετρήσεις | διορθωμένη τοπολογία + alerts | 94–99% |
| **Flagging** | τεκμηρίωση + μετρήσεις | κατάταξη ύποπτων ακμών | 25–93% precision |

Η τυφλή ανακατασκευή περιλαμβάνεται ως αξιολογημένο και απορριφθέν use
case (§3 της αναφοράς), όχι ως λειτουργία του service.

**Αντιστοίχιση με το D2.2**:

| D2.2 | Κάλυψη |
|---|---|
| Συναγωγή τοπολογίας από μετρήσεις | ✅ |
| Σύγκριση με asset DB | ✅ κύρια λειτουργία |
| Alerts για επαλήθευση από operator | ✅ και στις δύο λειτουργίες |
| Confidence score ανά σύνδεση | ⏳ βήμα 2 |
| Evaluation με withheld topology | ✅ |
| Reconstruction accuracy | ✅ |
| Edge precision & recall | ⏳ βήμα 3 |
| Επικύρωση καταστάσεων διακοπτών | ✅ (ΧΤ· ΜΤ εκτός) |
| Ανίχνευση αλλαγών μετά από switching | ⏳ βήμα 5 |
| Export | ⏳ βήμα 4 |
| Feeder assignment | ✗ εκτός αυτής της παράδοσης |
| Phase identification | ✗ εκτός αυτής της παράδοσης |

## 2. Βήματα

### Βήμα 1 — Αναδιοργάνωση repository · *μισή μέρα έως 1,5 μέρα*
Κατά το `REPO_REORGANIZATION.md`: πακέτο `topology/`, ένα script ανά πίνακα
στο `experiments/`, τα υπόλοιπα στο branch `archive`. Επαλήθευση ότι
αναπαράγονται τα ίδια νούμερα.

**Χωρίς νέα πειράματα σε αυτό το βήμα.**

### Βήμα 2 — Service API με confidence και alerts · *1 μέρα*

```python
from topology import validate_topology

result = validate_topology(
    measurements,               # τάση, προαιρετικά γωνία
    documented_topology,        # από το asset DB
    possible_connections=None,  # φυσικά υπαρκτές γραμμές/διακόπτες
)

result.topology      # διορθωμένη (αν δόθηκαν possible_connections)
result.alerts        # ασυμφωνίες με την τεκμηρίωση, ταξινομημένες
result.confidence    # score ανά ακμή
```

- Με `possible_connections` → λειτουργία διόρθωσης.
- Χωρίς → λειτουργία flagging.
- **Confidence**: σχετικό περιθώριο ηλεκτρικής απόστασης ανάμεσα στην
  επιλεγμένη ακμή και την καλύτερη εναλλακτική. Ο υπολογισμός υπάρχει ήδη,
  απλώς δεν εξάγεται.

### Βήμα 3 — Precision & recall στα αποτελέσματα · *μισή μέρα*
Το `evaluate` τα υπολογίζει ήδη. Προσθήκη στους πίνακες της αναφοράς.

### Βήμα 4 — Export · *μισή μέρα*
`to_json()` (τοπολογία + confidence + alerts) και `to_pandapower()`.
CIM/CGMES μόνο αν ζητηθεί ρητά.

### Βήμα 5 — Ανίχνευση αλλαγών μετά από switching · *1–2 μέρες*
Το μεγαλύτερο κενό απέναντι στα metrics του D2.2.
- Κυλιόμενο παράθυρο μετρήσεων· επικύρωση σε κάθε παράθυρο.
- Ελεγχόμενο πείραμα: αλλαγή κατάστασης διακόπτη σε γνωστή χρονική
  στιγμή.
- Metrics: καθυστέρηση ανίχνευσης, ποσοστό ψευδών alerts.
- Σημείωση: το 100% της §4.6 για ανοιχτό διακόπτη υποδεικνύει ότι η
  ανίχνευση θα είναι αξιόπιστη· το ανοιχτό ερώτημα είναι πόσο γρήγορα.

### Βήμα 6 — README · *μισή μέρα*
Εγκατάσταση, παράδειγμα χρήσης, εισόδοι/έξοδοι, όρια εφαρμογής.

**Σύνολο: 4–6 μέρες.**

## 3. Εκτός αυτής της παράδοσης

Να δηλωθούν ρητά ως μελλοντική εργασία:

- **Phase identification** — απαιτεί τριφασικό μοντέλο, όλα τα πειράματα
  είναι μονοφασικά ισοδύναμα.
- **Feeder / transformer assignment** — δεν έχει αξιολογηθεί ξεχωριστά.
- **Επικύρωση διακοπτών ΜΤ** — μόνο ΧΤ έχει δοκιμαστεί.
- **Field validation** — απαιτεί πραγματικά δεδομένα από τον DSO node.
- **Αυτόνομος εντοπισμός μη καταγεγραμμένων νέων γραμμών** — εκτός λίστας
  υποψηφίων η διόρθωση δεν λειτουργεί (§4.5).

## 5. Ερωτήσεις προς τον DSO / WP5

Ταξινομημένες κατά επίδραση στο αποτέλεσμα:

1. **Υπάρχει καταγραφή των φυσικά υπαρκτών συνδέσεων** — διακόπτες, tie
   lines, ανοιχτές γραμμές; Καθορίζει αν το service κάνει διόρθωση ή μόνο
   flagging.
2. **Καταγράφεται γωνία φάσης** ή μόνο μέτρο τάσης;
3. Σε ποια μορφή είναι το asset DB, και σε ποια μορφή θέλουν το export;
4. Κλάση ακριβείας των μετρητών και χρονική ανάλυση.
5. Είναι τα δεδομένα μονοφασικά ή τριφασικά;
6. Ποια είδη λαθών τεκμηρίωσης είναι συνηθέστερα στην πράξη;
